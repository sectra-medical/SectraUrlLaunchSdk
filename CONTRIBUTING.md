# How to contribute to Sectra URL Launch SDK

## Did you find a bug?

* **Do not open up a GitHub issue if the bug is a security vulnerability**, and instead to contact Sectra directly at <security@sectra.com>. Please include "Sectra URL Launch SDK" in the message title.
* **Ensure the bug was not already reported** by searching on GitHub under [Issues](https://github.com/sectra-medical/SectraUrlLaunchSdk/issues).

## Did you write a patch that fixes a bug?

* Open a new GitHub pull request with the patch.
* Ensure the PR description clearly describes the problem and solution. Include the relevant issue number if applicable.

## Features and feature requests?

* Feature requests should be discussed with your local Sectra representative for existing and new customers.
* New features are generally developed by Sectra. However, contributions are welcome but needs to be aligned with our current priorities and goals. Contact your Sectra representative for contact information to the development team.
